# 🎬 Movie Recommendation Website

A full-stack Movie Web that allows users to search and explore movie information using the TMDB API. Built with a **React frontend** and **Node.js Express backend**, this project showcases API integration, UI responsiveness, and state management in a modular structure.

---

## 📁 Repositories

- 🔗 **Frontend:** [movie-web](https://github.com/Malarselvimarimuthu/movie-web)
- 🔗 **Backend:** [movie-api](https://github.com/Malarselvimarimuthu/movie-api)

---

## 🚀 Features

### 🎞️ Frontend (`movie-web`)
- 🔍 Filter movies by name,language,actor,genre.
- 📽️ Watch official movie trailers
- ⭐ Add and manage favorite movies
- 🎨 Responsive UI using Tailwind CSS
- 📃 View detailed movie info


### ⚙️ Backend (`movie-api`)
- 🔌 Acts as a middleware to TMDB API
- 📥 Handles requests for search and movie details
- 🧩 Secured using `.env` file for API keys
- 🌐 Enables CORS for frontend access

---

## 🛠️ Tech Stack

| Layer      | Tech Used                          |
|------------|------------------------------------|
| Frontend   | React, Tailwind CSS, Axios         |
| Backend    | Node.js, Express, Dotenv           |
| API        | TMDB (The Movie Database) API      |
